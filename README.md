# Meuro website

Multi-page website for Meuro (African food, nutrition and wellness), opening with
**Meuro Market Run**, a 3D market game with email accounts, live races with
friends, shouts, crews and a leaderboard.

- `index.html` — Market Run game (entry page)
- `home.html`, `ai.html`, `foods.html`, `kitchen.html`, `nutritionists.html`, `about.html`, `faq.html` — website pages
- `backend.js` — live features on Firebase (Authentication + Realtime Database)
- `firebase-config.js` — paste your Firebase web app settings here
- `database.rules.json` — security rules for the Realtime Database
- `SETUP.md` — step-by-step guide to switch on the live features
